1. Executive Summary & Core Challenge

Modern OTT streaming platforms log millions of user interactions (watch time, session durations, genre preference distribution, completion rates). Raw logs cannot directly inform personalization rules. The objective is to build a lightweight, deterministic, containerized audience intelligence service that transforms tabular viewer logs into defensible behavioral clusters, exposes them via a production-grade REST API, and evaluates the entire lifecycle automatically.

Business Objective Why it matters

Replace generic one-size-fits-all recommendations with automated behavioral cohorts (e.g., distinguishing intense binge-watchers from casual short-form viewers and weekend binge explorers) to drive viewer retention and platform engagement.

Engineering Goal Deliverable

A turnkey, one-command (docker compose up --build) system connecting three microservices (trainer, api, evaluator) through shared Docker storage volumes, with deterministic seeding and independent evaluation.

⚠️ Non-Negotiable Core Principle & Constraints

Build the smallest system that proves the complete idea. Do NOT use LLMs (OpenAI, Claude, etc.), heavy transformers, or paid cloud APIs. No Jupyter notebook-only submissions. Do NOT retrain during inference. The core clustering task must remain purely unsupervised (do not invent pseudo-labels).

2. 3-Service Microservice Architecture

The system is strictly decoupled into three services communicating via volumes and HTTP networks:

1. Trainer Service Runs First
  • Loads user_activity.csv
  • Sanitizes & scales features
  • Computes optimal K (Elbow/Silhouette)
  • Fits KMeans/GMM deterministically
  • Maps centroids to human labels
  • Saves pipeline to /models/model.pkl
  • Exits cleanly with exit code 0
2. API Service Long Running
  • FastAPI running via Uvicorn
  • Loads model artifact into memory once
  • Exposes GET /health with readiness
  • Exposes POST /recommend
  • Strict Pydantic input validation
  • Returns segment, distance & recs
  • Monitored by Docker healthcheck
3. Evaluator Service Automated Verification
  • Waits until API is healthy
  • Submits standard test profiles
  • Executes 10 required edge cases
  • Calculates cluster stability & metrics
  • Generates metrics.json
  • Logs complete verification report

3. Machine Learning & Behavioral Feature Engineering

Feature Selection Matrix

Feature Category Raw Input / Extracted Feature Transformation & Behavioral Purpose
Engagement watch_time_hours, total_sessions Log-scale or StandardScaler. Distinguishes power binge-viewers from low-touch viewers.
Session Dynamics avg_session_mins Continuous numeric. Isolates casual snackable viewers (< 20m) from cinematic viewers (> 90m).
Content Preferences top_genres (list of strings) Multi-Hot Encoding / TF-IDF genre frequency vector across platform catalog.
Pattern & Diversity genre_diversity_score, weekend_ratio Entropy of genre distribution. Differentiates focused niche viewers from generalist explorers.

Optimal Cluster Selection & Cluster Profiles

Arbitrary selection of $K$ is penalized. The pipeline must compute:

  • Silhouette Coefficient ($s$): Target $s > 0.40$. Measures how tightly grouped clusters are versus neighboring clusters.
  • Inertia (Within-Cluster Sum of Squares): Elbow curve computed across $K \in [3, 8]$.
  • Cluster Balance Ratio: Verify no cluster has $< 5\%$ or $> 60\%$ of user population.

Segment Naming & Recommendation Logic

Cluster Segment Name Behavioral Signature Recommendation Catalog Strategy
High-Engagement Action Viewers High watch time (>30h/wk), high session mins (>80m), Action/Thriller dominance Blockbuster action franchises, high-octane thriller series, 4K HDR releases.
Casual Short-Session Viewers Low session duration (<25m), frequent visits, Comedy/Shorts Sitcoms, stand-up comedy clips, snackable web series, trending highlights.
Genre-Explorers High genre diversity (>0.7), medium-to-high watch time, varied categories Eclectic mix: curated indies, award-winning international cinema, docuseries.
Low-Activity Weekend Viewers Low total watch time (<5h), weekend concentrated, Family/Animation Popular crowd-pleasers, top 10 trending movies, low-friction family viewing.

5. Evaluator Service & Edge-Case Testing Matrix

The evaluator must run automated integration tests covering the 10 specific edge cases required by the competition:

Edge Case Scenario Input Payload Example Expected Handling & HTTP Status
1. Unknown / Unseen Genre {"top_genres": ["SpaceOpera", "UnknownXYZ"]} Gracefully ignore unknown genres or map to fallback; return 200 OK.
2. Empty Genre List {"top_genres": []} Default to zero genre vector; cluster by watch time/session metrics; return 200 OK.
3. Zero Watch Time {"watch_time_hours": 0.0} Valid lower bound; categorize into Low-Activity cluster; return 200 OK.
4. Extreme Numeric Outlier {"watch_time_hours": 999999.0} Clip to 99th percentile scaler ceiling; prevent overflow; return 200 OK.
5. Missing Required Field {"user_id": "USR-1"} (missing watch_time) Pydantic validation rejects payload; return 422 Unprocessable Entity or 400.
6. String in Numeric Field {"watch_time_hours": "twenty"} Reject non-numeric type with clean message; return 422/400 Bad Request.
7. Negative Numeric Values {"avg_session_mins": -15.0} Pydantic ge=0 validator catches negative values; return 422/400 Bad Request.
8. Idempotency Check Submitting exact same profile 5 times consecutively Verify 100% deterministic output (same segment_id & identical distance); return 200 OK.
9. Request Before Model Loads Client fires request before /models/model.pkl loaded API intercepts and returns 503 Service Unavailable (no crash or stack trace).
10. Cold Deployment / Missing Volume Container boots with empty /models/ directory API health check reports {"status":"degraded","model_loaded":false}; evaluator retries.

Complete docker-compose.yml Specification

version: "3.8"

services:
  trainer:
    build:
      context: ./trainer
      dockerfile: Dockerfile
    volumes:
      - model_volume:/models
      - ./data:/data:ro
    environment:
      - RANDOM_SEED=42
      - MODEL_PATH=/models/clustering_pipeline.joblib
      - METADATA_PATH=/models/metadata.json
    restart: "no"

  api:
    build:
      context: ./api
      dockerfile: Dockerfile
    ports:
      - "8000:8000"
    volumes:
      - model_volume:/models:ro
    environment:
      - MODEL_PATH=/models/clustering_pipeline.joblib
      - METADATA_PATH=/models/metadata.json
    depends_on:
      trainer:
        condition: service_completed_successfully
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:8000/health || exit 1"]
      interval: 5s
      timeout: 3s
      retries: 10
      start_period: 5s
    restart: unless-stopped

  evaluator:
    build:
      context: ./evaluator
      dockerfile: Dockerfile
    volumes:
      - ./metrics.json:/app/metrics.json
    environment:
      - API_URL=http://api:8000
    depends_on:
      api:
        condition: service_healthy
    restart: "no"

volumes:
  model_volume:
    driver: local
